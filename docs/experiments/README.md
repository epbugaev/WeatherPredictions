# Эксперименты по физике уравнений (WeatherGFT / PI-IAM4VP на ERA5)

Ветка `fix_inline_equations` (от `checker_equations` ← `refactoring`). Все эксперименты прогнаны на суперкомпьютере cHARISMa через `sbatch` (CPU-партиция `test`/`cpu-e-quick`, env `weatherpred-refactor`, torch 2.3.1) на **реальном ERA5** — USA-кроп 32×64 из memmap и глобус 128×256, собранный из netCDF `/home/fratnikov/weather_bench/1.40625deg/`.

Структура повторяет логические направления исследования. Каждая подпапка самодостаточна: скрипт → JSON-результаты → фигуры → отчёт `.md`.

## Сквозной вывод

Фикс 5 багов убирает катастрофические 10⁶× ошибки (необходимое условие конечности «чистой физики»), но **PDE-невязка одного шага остаётся ≫ 1** для всех переменных, регионов, границ и интеграторов. Ограничение — в **упрощённой форме уравнений** (нет диабатики, диагностическое w, неразрешённая орография), а не в численной схеме или геометрии. Реальный выигрыш — обучаемый физический член поверх исправленного RHS (см. `05_residual_regional/` §4, `03_new_block_audit/` P1–P5).
