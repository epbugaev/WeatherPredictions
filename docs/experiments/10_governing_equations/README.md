# 10. Governing equations audit — «берём ли мы не те уравнения?»

Литература (NeuralGCM/ClimODE/WeatherGFT) + 3 теста на ERA5. Вердикт: координаты
правильные (изобарические примитивные уравнения), но уравнения структурно неполны —
нет диабатики Q, неточная кинематическая ω, избыточно-прогностический z.

| Файл | Что |
|---|---|
| WRONG_EQUATIONS_AUDIT.md | Итоговый отчёт + рекомендуемый набор уравнений |
| lit_equations_comparison.md | Обзор уравнений SOTA-моделей |
| coordinate_mismatch.md | Формализация: код уже в координатах давления |
| omega_test.* | Тест A: качество кинематической ω (r≈0 с нужной) |
| diabatic_budget.png, diabatic_test.json | Тест B: диабатика в ~48× крупнее адиабатики |
| structure_test.* | Тест C: z избыточна (0.98), масштаб 1ч→6ч не помогает |
| wrong_equations_summary.png | Сводный вердикт по 4 гипотезам |

Главная рекомендация: убрать z из прогностических (диагностировать гидростатически),
добавить обучаемый диабатический член Q_θ на T и S_θ на q. Координаты и адиабатический
член оставить как есть.
