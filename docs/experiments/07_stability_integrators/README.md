# Устойчивость и интеграторы

Численная устойчивость pure-physics rollout нового `PurePDEKernel`: интеграторы, шаг по времени, схема адвекции, балансировка начального состояния. Все результаты консолидированы в `../03_new_block_audit/deep_audit_experiments.json` и на фигуре `../03_new_block_audit/deep_audit_hypotheses.png`.

## Скрипты

- **`dt_sweep.py`** — свип шага dt 300→150→75→37.5с. Шаг взрыва 12→17→25→42, но время до взрыва ПАДАЕТ (3600→1575с) → **сублинейно**, нелинейная grid-scale CFL.
- **`weno_test.py`** — гипотеза «схема адвекции виновата». WENO-5 + SSP-RK3 взрывается РАНЬШЕ (шаг 4 vs 11 у fd4-euler). **Гипотеза отвергнута.**
- **`balance_test.py`** — гипотеза «шок инициализации». `balance_initial_state` (none/dfi/geostrophic). Geostrophic — ХУЖЕ (взрыв на шаге 12 vs 16). **Гипотеза отвергнута.**

## Вывод

Неустойчивость «чистой физики» — **нелинейная grid-scale CFL** решётки lat-lon, а не ошибка одного компонента. Ни схема высокого порядка, ни балансировка IC, ни граничное условие её не устраняют — помогает только меньший dt (сублинейно). Согласуется с CHANGELOG-ablation E1–E6.
