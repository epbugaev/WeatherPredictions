# exp24 — метрики: хитмапы вкладов статики и физики (IAM4VP, USA)

Хитмапы «уровень × шаг» вклада каждого арма IAM4VP над выбранным контролем.
Формат и код — общий харнесс `tools/metrics_ladder.py` (как в exp16/20/21/22):
парный бутстрап, ограниченные метрики (ACC/CSI/FSS) — абсолютной разницей,
PSD — по модулю.

Контроль и сид — параметры `make_figures.py` (`--baseline`, `--seed`), каталоги
результатов:

| каталог | контроль | сид | эпохи |
| --- | --- | --- | --- |
| `results/iam4vp_usa` | `no_physics+orog` | s0 | разные (обрыв, 249–429) |
| `results/iam4vp_usa_nophys-static_s0` | `no_physics+static` | s0 | разные (обрыв, 249–429) |
| `results/iam4vp_usa_nophys-orog_s1` | `no_physics+orog` | s1 | **общая 499** |
| `results/iam4vp_usa_nophys-static_s1` | `no_physics+static` | s1 | **общая 499** |

## Главный вывод (чистый замер — seed 1, общая эпоха 499)

Относительно `no_physics+static` (полный статический вход orog+lsm):

| арм | RMSE Δ% (верхние каналы, 12 шагов) | значимо? |
| --- | --- | --- |
| `no_physics+orog` (убрать lsm) | **+0.06 %** [−0.46, +0.58] | нет — CI накрывает 0 |
| `a2+orog` (физика вместо lsm) | **−2.72 %** [−3.22, −2.21] | да |
| `a2+static` (физика + lsm) | **−2.77 %** [−3.25, −2.29] | да |

Читается так:

* **Маска суша/море (lsm) поверх орографии не даёт ничего** — убрать её (арм
  `no_physics+orog`) статистически неотличимо от нуля (+0.06 %, CI накрывает 0).
* **Орография — основной статический сигнал**; вся польза «констант» в exp24
  сидит в ней (см. также A/B `orog` vs `static` в `make_configs.py`).
* **Физика A2 даёт ~−2.7 % RMSE поверх полного статического входа** (значимо),
  то есть работает НЕ как замена географии, а сверх неё; добавление lsm к A2
  ничего не меняет (−2.72 vs −2.77, CI перекрываются).

Оговорка seed 0 ниже объясняет, почему на s0 «lsm выглядел полезным» (+0.83 %,
«значимо»): это артефакт разных эпох (orog@369 vs static@429), на общей эпохе он
исчезает.

## ⚠️ Оговорка seed 0: армы на РАЗНЫХ эпохах (last.pt)

Первичная волна s0 оборвана концом `proj_1715`, армы сняты на разных эпохах
last.pt, общей эпохи нет:

| арм | эпоха last.pt (s0) |
| --- | --- |
| `no_physics+orog` | 369 |
| `a2+orog` | 249 |
| `no_physics+static` | 429 |
| `a2+static` | 279 |

По уроку проекта (`val_plateau_not_skill_plateau`) разница в скилле на разбеге
эпох 249↔429 (~10 %+) **больше эффекта статики/физики (2–7 %)**, поэтому s0-хитмапы
**смешивают** вклад признака с недо-обучением. Именно это создало ложный
«lsm полезен» на s0. **Волна s1 (`proj_1717`) доведена до общей эпохи 499** и даёт
чистый замер — читать в первую очередь её (`*_s1`). Эпоха каждого арма — в его
подписи на фигурах; форест (`fig_ci_forest`) не строится (подпись утверждает
общую эпоху, что верно лишь для s1, — для единообразия опущен везде).

## Как пересобрать

```bash
# 1) eval на кластере (4 арма, USA) + парные дельты к nophys-orog.
#    SEED_TAG выбирает волну (s0 — историческая, s1 — общая эпоха на proj_1717).
SEED_TAG=s1 sbatch -A proj_1717 sh_files/exp24_metrics_eval.sh
# для дельт к другому контролю — пересчитать paired_deltas.py с нужным --baseline:
python docs/experiments/16_model_ablation_ladder/metrics/paired_deltas.py \
  --per-sample-dir ~/exp24_metrics_raw/iam4vp_usa_s1 \
  --baseline exp24-iam4vp-nophys-static-usa \
  --out ~/exp24_metrics_s1/paired_deltas_iam4vp_usa_vs_nophys-static.npz

# 2) скачать summary-npz + нужный paired_deltas (переименовать в paired_deltas.npz)
#    в results/iam4vp_usa_<baseline>_<seed>/.

# 3) фигуры под конкретный контроль/сид:
python docs/experiments/24_static_inputs/metrics/make_figures.py \
  --baseline nophys-static --seed s1
```

Выход в `results/<subdir>/`: `fig_levels_<метрика>.png` (сводные хитмапы,
строка = арм) + `heatmaps/<метрика>/<арм>.png` (пер-армовые) + `fig_psd.png` +
`metrics_table.md`.
