## 1. Суть

Эксперимент 10 заключил: «PDE-kernel решает изобарические примитивные
уравнения, `get_w` возвращает кинематическую ω, математика верна». Первая
половина верна, вторая — нет. Прошлый аудит прочитал `integral_z` как
∫₀ᵖ (сверху вниз), тогда как `M_z` — суммирование по j≥i, т.е. интеграл
**от уровня вниз к поверхности** (∫ₚ^{pₛ}). Отсюда:

- `d_z` = **−∂/∂p** (стенсиль `[-1, 8, 0, -8, 1]` — минус стандартного FD-4
  при индексе, растущем с давлением);
- `get_w` = −∫ₚ^{pₛ} div dp′ = **−ω** (вверх-положительная, гПа/с).

Эта пара **самосогласована** (эквивалентна координате ζ = −p): во всех
адвективных членах двойные инверсии знака взаимно гасятся — поэтому
adv-проверки exp 10 проходили. Но три места в коде предполагали конвенцию
+p / w=+ω, и именно они были сломаны:

| ID | Баг | Было | Стало |
|---|---|---|---|
| **B1** | Адиабатический член `get_t_t` | `ω = +100·w` → подъём **грел**, опускание охлаждало (анти-демпфирование) | `ω = −100·w` |
| **B2** | Гидростатический интеграл `get_z_t` | `z_zt = −R/p·t_t` при интеграле уровень→поверхность → `z_t = −Φ_t` (прогрев столба **опускал** геопотенциал) | `z_zt = +R/p·t_t` |
| **B3** | Уравнение состояния в q-блоке | `ρ = −1/z_z`, `p = ρ·R·t` (R=8.314) → **p = −14.8 Па** вместо 50 000 Па → q_s→1e-6, конденсация мертва; триггер δ срабатывал на **опускании** | реальные давления уровней (буфер `pressure`), `ω = −100·w`, δ = (ω<0 ∧ q≥q_s), источник `δ·F·ω/p` (насыщенная псевдоадиабата, Haltiner & Williams) |
| **B4** | Магнус в `physics.py._get_qs` | batch-global `_scale_tensor` (баг №4 exp 01 остался неисправленным в диагностической библиотеке) + клемп [−3.47, 3.01] | поэлементный `clamp(±20)` как в `saturation_specific_humidity` |

Правки зеркальны в обоих модулях (`PDE_kernel` — обучаемый прайор PI-моделей;
`PurePDEKernel` — диагностика/check_physics). `_si_setup` semi-implicit
reference-оператора синхронизирован текстуально (два флипа гасятся — матрица A
численно не изменилась). Ветка `t_t_formulation='legacy_paper'` не тронута
(байт-в-байт, запинено голденом).

## 3. Следствия для прошлых выводов

1. **«Невязка ≫ 1 при численно верном ядре» (exp 04/11)** — ядро не было
   численно верным: у 2 из 5 уравнений ведущий член имел неверный знак
   (ошибка 2× амплитуды сигнала), q-источник был мёртв. Невязки надо
   пересчитать; вывод «ограничение — в форме уравнений» может ослабнуть.
2. **«Интеграторы не помогают» (exp 07)** — согласуется с физически растущей
   модой от анти-демпфирующей адиабаты (B1), а не с CFL (на v4-геометрии
   CFL_adv ≈ 0.06, CFL_грав ≈ 0.36). После фикса пересмотреть выводы о
   стабильности pure-physics.
3. **«Диабатика ×48» (exp 10, тест B)** — остаток Q содержал 2× амплитуды
   перевёрнутой адиабаты; оценку пересчитать (ожидание: заметно меньше ×48,
   но всё ещё ≫ 1 — диабатика реально отсутствует).
4. **«ω завышена ×10, r ≈ 0» (exp 10, тест A)** — величина остаётся в силе
   (кинематическая ω на 8×16 шумна), но корреляцию мерить с −w; знак больше
   не портит адиабату.
5. **Метрики check_physics по q** до этого фикса дополнительно искажались
   B4 (batch-remap в `_get_qs`).

## 4. Что осталось НЕ исправленным (сознательно, вне скоупа фикса)

- Кинематическая ω шумна на 8×16; `mass_consistent` — паллиатив
  (арм massconsistent), ω-уравнение — открытая задача.
- Forward Euler + WENO без flux-splitting — для pure-physics/dynamical-core
  нужен SSP-RK3/semi-implicit (пересматривать exp 07 после фикса).
- Граница reflect: нулевая производная в первом узле оси, 4/8 строк латента
  в зоне паддинга (смотреть `physics_residual_delta_edge_interior_ratio`).
- Клемп Магнуса ±20 завышает q_s при T < −35 °C умеренно (см.
  docs/consistency.md); метрические члены сферы, трение, диабатика Q —
  отсутствуют (Q_θ-арм адресует последнее).
- Обученные армы v4 (fixv2-purephys) тренировались на до-фиксовой физике:
  их physics-фичи содержали B1–B3; **метрики через границу фикса
  несравнимы**, армы нужно перезапускать.
