# Эксперимент 18 — послойный (по высоте) разбор вклада физики

**Вопрос.** Обученные армы лестницы экспа 16 (t=12) на одних уровнях давления
прогнозируют лучше базовой модели без физики, на других — хуже. **Почему —
сугубо физически?** Здесь связываем послойный *скилл* обученной модели с
послойной *корректностью уравнений* ядра, измеренной напрямую на реальном ERA5.

**Итог (TL;DR).** Для **прогностических** переменных (T, u, v) физика улучшает
уровень ровно там, где невязка уравнения на ERA5 `residual_rel ≲ 1`
(тенденция ловит сигнал), и вредит там, где `≫ 1`: ветер выигрывает по всей
свободной тропосфере (resid 0.6–1.2) и проваливается в пограничном слое
(resid → 3.6, Экмановский баланс не по зубам трению Рэлея) — корреляция
Δскилл×невязка для u = **+0.58**. Для **диагностических** переменных принцип
гнётся: **z** (гидростатический интеграл) выигрывает наверху за счёт структурной
когерентности столба, а не поточечного замыкания (корреляция инвертирована −0.68);
**r** меряется на r, а эволюционирует на q — мост Клаузиуса–Клапейрона рвёт связь
(corr +0.05), и «влажностный налог» 600–700 гПа невидим в q-невязке.
**Пограничный слой (≲ 850 гПа) — универсальная зона отказа** для всех переменных →
рычаг: маска уровня для физического приора. Данные: rollout экспа 16 (t=12,
эпоха 90) + диагностика ERA5 USA 2004.

---

## 1. Данные и метод

Две независимые величины на каждый из 13 уровней давления
`[50, 100, 150, 200, 250, 300, 400, 500, 600, 700, 850, 925, 1000]` гПа:

**(A) Наблюдаемое — послойный скилл обученной модели.** Rollout экспа 16
(`../16_model_ablation_ladder/rollout_eval.py`) пишет lat-weighted RMSE каждого
из 69 каналов (= 13 уровней × {z, T, r, u, v} + 4 приземных) в физических
единицах, по 12 шагам прогноза, на полной валидации USA. Метрика вклада физики —
относительная дельта к арму без физики R0:

```text
delta[var, level] = (RMSE_arm − RMSE_R0) / RMSE_R0 · 100 %      (<0 — физика лучше)
```

**(B) Объясняющее — послойная корректность уравнений на данных.**
`level_diagnostics.py` (USA 2004, часовые тройки снимков ERA5) считает для трёх
конфигураций ядра:

* `residual_rel[level] = Σ|obs_t − rhs_t| / Σ|obs_t|` — относительная невязка
  уравнения на уровне. Интерпретация:
  * **< 1** — тенденция ядра ловит часть истинной тенденции (**физика права**);
  * **≈ 1** — тенденция ≈ 0 либо ошибка = сигналу (**физика инертна/бесполезна**);
  * **≫ 1** — тенденция больше самого сигнала и неверна (**физика впрыскивает шум**).
* `term_abs_over_obs[level]` — магнитуда каждого члена правой части, делённая на
  `|obs_t|`: какой член (гидростатика/адиабата/адвекция/трение/Кориолис/латентное
  тепло) доминирует невязку на данной высоте.

**Тезис (проверяемый на данных).** Физ-арм улучшает уровень там, где невязка
ядра < 1, и вредит/нейтрален там, где ≫ 1 или ≈ 1. Проверяется корреляцией
`delta[var, :]` против `residual_rel[var, :]` по 13 уровням.

### Отображение армов на конфигурации ядра

Диагностика считает три «якоря», совпадающих с уравнениями ступеней лестницы:

| Якорь ядра | Уравнения | Арм экспа 16 |
|---|---|---|
| `base13` | легаси (до знаковых фиксов), linspace-широты | **R1** legacy-hybrid |
| `C_best` | геометрия сферы exp14: metric/spherical/rayleigh, exact dx, mass-consistent ω | **R4** exp14 |
| `C15_now` | + скрытое тепло конденсации + omega_free(T,q) (exp15) | **R5** exp15 |

R3/R3a/R3q (только знаковые фиксы exp13, без геометрии exp14) — промежуточная
ступень: их невязки лежат между `base13` и `C_best`. Отдельным якорем не
считаются, чтобы не выдумывать неточное отображение.

**Оговорка по влажности.** Скилл меряется на `r` (отн. влажность), а невязка
ядра — на `q` (уд. влажность): ядро внутри переводит r→q, применяет тенденцию q
и переводит обратно. Связь r↔q монотонна, но зависит от T (Клаузиус–Клапейрон),
поэтому послойное сопоставление r-скилла с q-невязкой — качественное.

### Физический фон членов ядра (пять уравнений)

* **z (геопотенциал)** — не прогнозируется отдельным уравнением: тенденция
  `z_t` получается гидростатическим интегралом тенденции температуры
  `z_t = −R_d ∫ T_t d ln p` (уровень → поверхность). Значит послойный скилл z
  наследует качество T_t и точность вертикального интегрирования.
* **T (температура)** — `T_t = −адвекция − ω ∂T/∂p + (R_d T ω)/(c_p p) + Q/c_p`.
  Адиабатический член `(R_d T ω)/(c_p p)` и вертикальная адвекция завязаны на ω
  (диагностическую вертикальную скорость); диабатический `Q/c_p` — скрытое тепло
  конденсации (exp15) или обучаемый диабатик Q_θ.
* **r/q (влажность)** — `q_t = −адвекция − ω ∂q/∂p + конденсация`; сток при
  пересыщении. Обучаемый диабатик в режиме `t_and_q` даёт дополнительный
  влажностный член.
* **u, v (ветер)** — `u_t = −∇·(uV) + f v − ∂z/∂x + метрика + трение`. В средних
  широтах барический градиент `−∂z/∂x` и Кориолис `f v` почти уравновешены
  (геострофия) → тенденция = малый *агеострофический остаток* большой разности,
  чувствительный к геометрии и трению.

## 2. Послойный скилл (наблюдаемое)

Полная таблица — `results/mechanism_digest.md` и `results/level_delta_table.md`;
фигуры `figures/fig_level_skill_mean.png` (среднее по 12 шагам),
`figures/fig_level_skill_first.png` (шаг 1). Структура вклада физики (арм R5,
Δ% к R0, среднее по 12 шагам; знак «−» = лучше):

| переменная | свободная тропосфера (100–700 гПа) | пограничный слой (850–1000) |
|---|---|---|
| **z** | −3…−9 % (улучшение, макс. на 150–400) | 0…+2 % (нейтрально/слегка хуже) |
| **T** | −1…−6 % (мягкое улучшение) | ≈0 (нейтрально) |
| **r** | пятнисто: −4…−7 % на 100/400–500, +1…+2 % на 600–700 | +2…+4 % (хуже) |
| **u** | −1…−4 % (улучшение) | +0.5…+1 % (хуже) |
| **v** | −1…−4 % (улучшение) | +0.8 % на 925 (хуже) |

Два сквозных факта:

1. **Пограничный слой (850–1000 гПа) — зона, где физика перестаёт помогать или
   вредит** для ветра, влажности и приземного z; свободная тропосфера — где
   помогает. Граница резкая (см. u: −2.3 % на 850 → +1.2 % на 925).
2. **Короткий лид выигрывает многократно сильнее.** На шаге 1 (столбец `first`)
   физика улучшает на порядок больше: z@400 R5 **−29 %**, u@50 R4 **−16 %**,
   v@100 R4 **−28 %**, T@600 R5 **−14 %**. Усреднение по 12 шагам разбавлено
   накоплением дрейфа free-running rollout, но знак и вертикальная структура
   сохраняются.

Легаси-физика (R1) — почти зеркало: в свободной тропосфере преимущественно
**вредит** (z 200–700 +5…+8 %, v 300–500 +3 %), что делает её структурным
потолком экспа 16.

## 3. Послойная корректность уравнений (объясняющее)

Невязки и магнитуды членов — `results/eq18_usa_2004.json` (USA 2004, 8782 тройки
снимков); scatter `figures/fig_residual_vs_skill.png`. Структура невязки
`residual_rel` строго повторяет структуру скилла:

| переменная | легаси (R1 / base13) | exp14–15 (R4/R5) |
|---|---|---|
| **z** | катастрофа наверху: **356** @50, 124 @100 → 1.0 @1000 | приручена: 7.3 @50 → 1.05 @1000 |
| **T** | катастрофа наверху: **105** @50 → 1.4 @1000 | R5 уплощена до **~1.0** на всех уровнях |
| **q** | плохо наверху: 19–23 @50–100 | R5 **<1** в средней тропосфере (0.85 @600) |
| **u** | 2–10 везде | **<1** в свободной тропосфере, **3.6** @1000 |
| **v** | 6–16 везде | **<1** в свободной тропосфере, **3.3** @1000 |

Что показывают магнитуды членов (кто правит невязку):

- **z**: доминирует `from_nonadv` — гидростатический интеграл неадвективной части
  T_t (у легаси **384×** @50, у R5 12×); ошибка накапливается сверху вниз.
- **T легаси**: сломанный **адиабатический** член `(R_d T ω)/(c_p p)` = **104×**
  сигнала @50; exp15 `omega_free` его срезает → остаётся `adv_h` (~1) → невязка ~1.
- **u/v**: `pgf ≈ coriolis` (оба 1.5–7.6×, почти взаимно сокращаются) — тенденция
  есть малый **агеострофический остаток**; у поверхности баланс переключается на
  `pgf` (5.4 ≫ coriolis 2.8), а трение Рэлея (0.2–0.4) слишком грубо для
  Экмановского слоя → невязка взлетает.

**Дискриминатор — невязка** (scatter `fig_residual_vs_skill.png`): легаси-физика
(R1) живёт при `residual ≫ 1` → Δскилл **положительна** (вредит); exp14/15
(R4/R5) живут при `residual ≈ 1` (u/v/T/q) → Δскилл **отрицательна/нейтральна**
(помогает). Корреляция Δскилл×невязка по 13 уровням для **u = +0.58** (чистое
подтверждение тезиса для прогностического импульса). Для **z корреляция
инвертирована** (R4 −0.68): z — диагностическая переменная (гидростатический
интеграл), её скилл определяется вертикальной структурной когерентностью, а не
поточечным замыканием тенденции (разбор в §4).

## 4. Механизм по переменным

Разбор проведён по трактовке данных (числа сверены с `results/level_summary.json`
и `results/eq18_usa_2004.json`).

### z (геопотенциал)

**z — диагностическая переменная, и это задаёт всю вертикальную структуру
скилла.** В ядре z_t не имеет собственного уравнения: z_t = −R_d ∫ T_t d ln p от
якоря Φ_t(p_s)=0 у поверхности (`get_z_t`, правка B2). Два конструктивных
следствия. Во-первых, путь интегрирования растёт с высотой — z_t(p) собирает T_t
всего слоя между p и поверхностью, поэтому невязка накапливается кверху даже у
«правильного» ядра: resid_z(R5) = 1.05 (1000 гПа) → 7.3–8.6 (50–100 гПа) при
попутном resid_t(R5) ≈ 1.01–1.19 на всех уровнях. Во-вторых, у якоря правая часть
занулена по построению: |from_adv| = 0.09 и |from_nonadv| = 0.14 от |obs z_t| на
1000 гПа. Значит resid ≈ 1.0–1.3 на 850–1000 — признак не точного уравнения, а
инертного: приор утверждает z_t ≈ 0 и сигнала не несёт.

**R1: знаково-сломанный интегранд — «медленный яд» средней тропосферы.**
Легаси-адиабата (до фикса B1) завышает правую часть T_t на 1–2 порядка
(|adiabatic|/|obs T_t| = 104 @50, 26 @250, 11 @500), и гидростатический интеграл
разносит это по столбу: resid_z(R1) = 356 @50 и 23.8 @200 против 7.3 и 3.2 у R5
(×49 и ×7.5). При этом на шаге 1 R1 ещё помогает z (в среднем −15.3% по 150–500,
до −22.1 @150): статичное смещение, действующее на истинное состояние, корректор
частично снимает за один шаг. В 12-шаговом free-running смещение прикладывается к
уже дрейфующему состоянию и накапливается: все семь уровней 200–700 уходят в плюс
(шесть из них +5.7…+8.2%, среднее полосы +5.9%) — когерентная вертикальная
структура, а не шум одиночной ячейки (±5–8 п.п.). Полоса вреда ложится туда, где
базе есть что терять: RMSE mean/first у R0 на 200–700 равно 1.27–1.45, тогда как
на 50–150 база почти выходит на плато уже к шагу 1 (1.15–1.20) — потому та же
отрава даёт там Δ ≈ 0 (−0.3…+1.9%). Вред виден и в самой T (ΔT(R1) = +4.5% @400,
+2.2% @250), а z наследует его интегрально.

**R4/R5: правило «resid<1 → польза» для z инвертируется, потому что скилл задаётся
когерентностью столба, а не поточечным замыканием.** По уровням corr(Δ, resid_z) =
−0.68 у R4: чем больше невязка, тем сильнее выигрыш. Механизм: после знаковых
фиксов exp13 и геометрии exp14 интегранд верен по знаку и вертикальной форме, а
остаточная невязка наверху — гладкое завышение амплитуды (from_nonadv = 11–14×
|obs z_t| на 50–150). Мультипликативную вертикально-когерентную ошибку обучаемый
корректор снимает по-уровневым усилением; чего он не синтезирует сам —
фазово-структурную информацию интеграла столба. Она и даёт выигрыш там, где путь
интегрирования глубок и бароклинный сигнал велик: в среднем −4.5% (R4) и −5.9%
(R5) на 100–500, пики −9.2…−9.5% при базовой RMSE 132–154 м. У поверхности всё
наоборот: усиливать нечего (ПЧ ≈ 0), а реальная приземная z_t управляется
динамикой p_s, пограничным слоем и орографией, которые фиксированный якорь
Φ_t(p_s)=0 явно зануляет (кинематический якорь — opt-in). Приор здесь — чистый
налог на корректор: +4.1% (R4) и +6.5% (R3q) в среднем на 850–1000. Что это
отсутствие сигнала, а не только дрейф, показывает шаг 1: на 150–500 физика даёт
−20…−32%, на 850–1000 — уже +0.2…+7.1%.

**omega_free (R5 против R4) чистит интегранд, не меняя его амплитуды.** Замена
mass-continuity ω на локальное (T,q)-замыкание схлопывает невязку T с 1.1–4.0 до
1.01–1.19 по столбу при практически неизменных магнитудах z-интегранда
(from_nonadv @100: 14.25 → 14.17). Эффект в z структурный: полоса пользы
становится сплошной (150–600 гПа: −2.3…−9.5% без смен знака — против провала R4 на
250–300: +1.1/+1.5%), приповерхностный налог падает с +4.1 до +1.1 п.п., а
corr(Δ, resid) уходит к −0.07 — польза перестаёт следовать за профилем невязки.
Единственная потеря R5 (+2.3 @50 против −7.6 у R4) — одиночная ячейка внутри
шумовой полосы, вывод по ней не делается.

**Короткий лид против среднего.** На шаге 1 тенденциальный оператор действует на
истинное состояние и даёт до −32.2% @250 и −29.3% @500 (R5); к среднему по 12
шагам это разбавляется до −5…−9%, так как в rollout приор считается от дрейфующего
состояния, а сама база растёт к насыщению. Это тот же водораздел, что в
rollout-диагностике exp16: пост-exp13 армы удерживают знак выигрыша по всему
горизонту, R1 переворачивается (−16.5% → +1.5% @400).

### T (температура)

Термодинамическое уравнение `T_t = −adv_h − ω∂T/∂p + R_dTω/(c_p p) + Q/c_p`
содержит пару ω-членов, которые в реальной атмосфере почти компенсируются: их
разность — член статической устойчивости ω·S_p, и при γ≈6.5 К/км (против
сухоадиабатических 9.8) S_p составляет лишь ~1/3 каждого слагаемого (на 400 гПа:
R_dT/(c_p p)≈1.8·10⁻³ К/Па против ∂T/∂p≈1.2·10⁻³, нетто 0.6·10⁻³). Поведение
T-приора по уровням определяется тем, что каждый арм делает с этой плохо
обусловленной парой.

**1. Легаси (R1): вред не там, где невязка максимальна.** resid_R1 растёт к верху
как 1/p (104.7 @50 → 1.4 @1000), и источник — сломанная адиабата: |член|/|сигнал|
= 104.4 @50, 45.8 @150, 16.2 @400, но лишь 2.7 @850 и 0.6 @1000; плюс adv_v на
сломанной ω (11.0 @150, 12.5 @400). Однако Δскилл немонотонен по амплитуде
поломки: максимум вреда на 150 (+3.5%) и 400 (+4.5%), а не на 50 (+1.4%).
Механизм — идентифицируемость мусора: член, на два порядка превышающий всё
остальное, линейно отделим, и обучаемый гибридный вес его зануляет (шаг 1: R1@50
−0.6%, @100 −6.5% — подавление срабатывает сразу). Опасна зона O(10)×: на 400 пара
adv_v 12.5 / адиабата 16.2 взаимно гасится до невязки 4.1 на истинных полях
(16.2−12.5≈3.8≈resid), но на прогнозных полях компенсация рушится, и впрыскивается
шум масштаба слагаемых (~12–16× сигнала), неотделимый от реальной динамики (@400
уже на шаге 1 +5.5%). У поверхности члены ≤O(1) — явный множитель 1/p и ω→0 у
нижней границы — и эффект тонет в шуме (+0.3…+1.7%).

**2. R5: усечение до adv_h — безвредный, но информативный приор.** omega_free(T)
удаляет из выхода обе половины плохо обусловленной пары; невязка уплощается до
1.01–1.19 против 1.1–4.0 у R4. Показателен провал R4@400 (+4.5%): он колокализован
со столбцовыми максимумами ω-членов C_best (adv_v 3.48, адиабата 4.48 — оба пика
на 400) при внешне благополучной невязке 1.13, т.е. проблема в обусловленности
разности больших членов, а не в нетто-смещении; удаление пары переводит уровень в
−1.4%. Оставшийся adv_h имеет амплитуду 0.45–1.30 и положительную проекцию на
истинную тенденцию. Максимум пользы: 600 гПа (−5.7%, на шаге 1 −14.4% — крупнейший
одноуровневый выигрыш по T) — средняя тропосфера, где бароклинная горизонтальная
адвекция доминирует в синоптической изменчивости T, вдали и от погранслойной
диабатики, и от тропопаузы; и 100 гПа (−5.5%) — стратосфера, где стратификация
подавляет ω, динамика квазигоризонтальна, и adv_h-only близок к истинному балансу
(resid 62.9→1.18). У поверхности выигрыш исчезает (+0.9…+1.4%): T погранслоя
управляется потоками с поверхности и суточным ходом, отсутствующими в уравнении
(adv_h падает до 0.45–0.68). Сам latent-член мал всюду (пик 0.06 @400) — выигрыш
R5 по T обязан omega_free, а не энергосвязке. Особняком 150 гПа, враждебный всей
лестнице (лучший арм −0.1%): в домене USA это уровень максимального пересечения
тропопаузы, ∂T/∂p меняет знак внутри шага 13-уровневой сетки, и даже adv_h
переобъясняет тенденцию (1.08 при resid 1.19).

**3. R3q: несбалансированный нагрев — термодинамическая яма на 850.** В режиме
t_only Q_θ греет T без стока q: скрытое тепло «выделяется» без конденсации,
нарушая связку dT = −(L/c_p)dq. На 850 гПа — максимуме влагосодержания и
конденсационного нагрева (вершина погранслоя, тёплые сектора циклонов) — это даёт
+5.5% против +0.4% у R3 (t_and_q) и −0.4% у R3a (без Q_θ). Диагностично: на шаге 1
R3 и R3q на 850 неразличимы (оба +2.4%) — дисбаланс невидим одношагово; весь вред
— rollout-амплификация: нагретый, но не осушённый воздух на следующем шаге снова
«конденсирует», обратная связь не самоограничивается, тогда как в t_and_q сток
влаги выключает нагрев. Порядок R3a < R3 ≪ R3q — несбалансированный нагрев хуже
отсутствия нагрева — прямое обоснование дизайна t_and_q.

**4. Короткий лид — чистый физический сигнал.** На шаге 1 R5 улучшает T на −8…−14%
по всей свободной тропосфере (−10.7 @200, −8.9 @500, −14.4 @600) против
разнознакового R1 (+5.5 @400, +6.9 @850). Приор — модель одношаговой тенденции;
среднее по 12 шагам (−0.9…−5.7%) разбавлено накопленным дрейфом rollout, но
ранжирование уровней сохраняется.

### r (относительная влажность)

**Диагностическая переменная с двумя хозяевами.** r — единственный канал, где
скилл и невязка живут в разных пространствах: ядро интегрирует уравнение для q
(−адвекция_h − ω∂q/∂p + конденсация), а RMSE считается на r = q/q_sat(T,p). Мост
нелинеен: δln r = δln q − (L/(R_v T²))·δT, т.е. температурная ошибка входит в r с
плечом Клаузиуса–Клапейрона: ≈7 %/К при 270–280 К (600–700 гПа) и ≈14 %/К при
210 К (100 гПа, сублимация надо льдом). Поэтому q-невязка — маргинальная метрика,
а r-скилл — функционал *совместного* распределения ошибок (δq, δT). Отсюда
«пятнистость» профиля: corr(Δr, resid_q) по 13 уровням у R5 всего **+0.05** (у u —
+0.58) — послойная корректность q-уравнения почти не предсказывает r-скилл. Вторая
причина: R0 обучается прямо на r и неявно ко-калибрует ошибки q и T так, чтобы они
сокращались в частном q/q_sat; физприор правит q и T *разными* членами
(влагоадвекция vs адиабата) и разрушает эту ковариацию — маргинальные выигрыши не
обязаны переноситься в r.

**r@100 — температурный выигрыш, а не влажностный.** Все восемь армов дают
−4.0…−6.7 %, включая R1, у которого q-уравнение до знаковых фиксов — шум
(resid 23). Значит канал переноса — не q-динамика. У холодной тропопаузы ln q_sat(T)
крут: базовая T-ошибка R0 1.17 К при 14 %/К и r ~ 20–40 % даёт 3–6 п.п. — масштаб
всей базовой r-RMSE (3.85 п.п.). Физика улучшает t@100 на −2.2…−5.5 % у всех
армов, и холодное плечо конвертирует это в r почти один-в-один. @50 гПа r-канал
почти константа (R0_RMSE 0.50 п.п.), проценты косметические.

**400–500 гПа: влажностная часть Q_θ ловит осадочный сток.** Изоляция чистая: R3
(t_and_q) −4.0/−3.1 %, тогда как R3a (без диабатика) −0.9/+0.2 и R3q (t_only)
−0.1/+1.0. Этот слой — зона крупномасштабной конденсации и осадкообразования
(тёплые конвейеры циклонов, детрейнмент наковален МКС над США): влага
систематически уходит из q в осадки. Разрешённая адвекция там уже хороша
(resid 0.92/0.86, adv_h 0.87/0.83), а зашитая конденсация слаба (|cond|/|obs_t| =
0.10/0.05 при пике 0.16 @250) — незамкнутый остаток тенденции и есть осадочный
сток, привязанный к распознаваемому паттерну насыщенного подъёма, поэтому Q_θ^q
его выучивает. Диагностическая невязка Q_θ не содержит, так что resid<1 и выигрыш
диабатика — независимые свидетельства. Q_θ^t по построению этого не может: нагрев
без осушения сток не воспроизводит.

**600–700 гПа: налог, где ломается «resid<1 → помогает».** q-невязка здесь лучшая
по столбу (0.85/0.86), T улучшается (t@600: R3 −3.5, R3a −3.3, R5 −5.7 %), а r хуже
у всех восьми армов (600: +0.4…+2.5; 700: +1.4…+2.2), в том числе без диабатика
(R3a +0.8/+2.0). Два механизма. (1) Мост q→r: при T-RMSE 0.92–1.00 К плечо 7 %/К и
r~50 % дают ~3–3.5 п.п. T-вклада в 12-п.п. бюджет r; физика уменьшает |δT| и |δq|
порознь, но декоррелирует их — и частное q/q_sat теряет компенсацию, встроенную в
R0. (2) Незамкнутые ~15 % тенденции — не шум: 600–700 гПа над континентом — верх
влажного пограничного слоя/слой детрейнмента мелкой конвекции с самым резким
∂q/∂p; недостающий член — систематический конвективный подток влаги снизу, и
адвективный приор полной амплитуды без него смещён в сухую сторону. Характерно,
что у диабатических армов налог максимален уже на шаге 1 (R3 +5.5/+6.2, R5
+4.6/+4.6 — смещение самой впрыскиваемой тенденции), а у R3a накапливается по
роллауту. Урок: невязка в q-пространстве — необходимое, но не достаточное условие
r-скилла для диагностической связки r↔(q,T).

**1000 гПа: свободноатмосферная физика на чужой территории.** У земли q-уравнение
инертно (resid 1.01, adv_h 0.44, cond 0.00): испарение с поверхности, турбулентное
перемешивание, суточный ход — вне ядра. Налог растёт монотонно с амплитудой
применённой физики: R3a −0.1 → R3 +0.9 → R4 +2.7 → R5 +3.6 %. Геометрический фикс
exp14 (dx ×4) довёл адвективный приор до физической амплитуды — и тем усилил
смещение незамкнутого уравнения у земли; exp15 добавил latent-связку у поверхности
(t@925/1000 R5 +1.4/+0.9 — ложный нагрев в ночном насыщенном погранслое) и через
q_sat портит r и на 925 (+2.0). Практический вывод: влажностный приор ниже
~925–850 гПа стоит гасить маской уровня, пока в ядре нет схемы пограничного слоя.

### u, v (горизонтальный ветер)

Физическое ядро с точной геометрией помогает обеим компонентам почти во всей
свободной тропосфере и выключается в пограничном слое. У R5 Δ<0 на всех 10 уровнях
50–700 гПа по u (−0.3…−4.2 %) и на 9 из 10 по v (до −3.6 %); 925 гПа — единственный
систематический плюс во всех армах (u +1.2, v +0.8 у R5). Ровно эту стратификацию
предсказывает невязка уравнения импульса: resid_R5 = 0.62–1.02 (u) и 0.84–1.19 (v)
на 50–700 гПа против 1.3→3.6 к поверхности; корреляция Δ×resid по 13 уровням:
u +0.58, v +0.24. R5 не трогает уравнение импульса, поэтому пара R4/R5 — две
реализации одной физики: их расхождения (±1–2 п.п.) задают масштаб траекторного шума.

**Свободная тропосфера (50–700 гПа): тенденция — малый агеострофический остаток.**
Магнитуды членов у R5 дают количественную геострофию: |f·v|/|∂u/∂t| = 2.8–3.9 на
100–700 гПа, |∂z/∂x| сопоставим (1.5→5.4 к поверхности), адвекция — лишь 0.32–0.51.
Каждый ведущий член в 3–4 раза больше самой тенденции: pgf и Кориолис гасятся на
~70–75 %, и ∂u/∂t — их малая разность. Следствие: относительная ошибка любого
большого члена входит в тенденцию усиленной в |pgf|/|u_t| ≈ 3–5 раз — у геометрии
нет права на ошибку. Пакет exp14 — точный dx (1.40625° вместо ×4), точные широты
(→ f), сферическая кривизна, d_y юг→север — переводит уравнение в режим «ловит
сигнал» (resid_R5 0.62–1.19), и приор инжектирует правильный агеострофический
остаток. Чистый физсигнал — на шаге 1: u R4 −9.6…−16.8 % (100–300 гПа), v@100
−28.1 %; среднее по 12 шагам (−1…−4 %) разбавлено дрейфом — накопленные ошибки z
подмешиваются в pgf следующих шагов.

**Пограничный слой (850–1000 гПа): экмановский баланс, который нечем замкнуть.**
Ниже 850 гПа доминирующий член переключается coriolis→pgf: на 1000 гПа |pgf| = 5.4
(u) и 4.9 (v) против |f·V| ≈ 2.8. Дисбаланс ~2.6 единиц |∂u/∂t| в реальной
атмосфере закрывается вертикальной дивергенцией турбулентных напряжений —
экмановским поворотом ветра на 20–40° поперёк изобар. В ядре вместо этого трение
Рэлея −V/τ магнитудой 0.21–0.40 (u) / 0.16–0.36 (v): почти на порядок слабее
требуемого, антипараллельно ветру (гасит, а не поворачивает) и без зависимости от
статической устойчивости и суточного цикла. Уравнение перестаёт замыкаться —
resid u: 1.31→1.77→3.61, v: 1.29→1.69→3.26, хуже прогноза нулевой тенденции, — и Δ
уходит в ноль/плюс. Характерно, что худший уровень — 925, а не 1000 гПа: там
физика вредит уже на шаге 1 (u +10.5, v +15.4 %). 925 гПа над США — ядро ночного
низкоуровневого струйного течения Великих равнин, чисто агеострофической
инерционной осцилляции после вечернего отключения трения; линейный drag с
фиксированным τ такую струю гасит, а не воспроизводит. На 1000 гПа приор настолько
плох (resid 3.3–3.6), что корректор его фактически обнуляет (Δ от −0.7 до +0.5),
тогда как на 925 он «правдоподобно неверен» (resid ~1.7): достаточно похож на
правду, чтобы просачиваться, и достаточно неверен, чтобы вредить.

**Легаси (R1) против геометрии (R4): арифметика убитого барического градиента.**
resid_R1(v) = 6.2–16.4 — количественный отпечаток переворота ∂z/∂y. При ориентации
d_y, обратной хранению данных (ряды юг→север), меридиональный pgf не компенсирует
−f·u, а складывается с ним: ожидаемая невязка ≈ (|pgf|+|f·u|)/|v_t| ≈ 2·(ведущий
член). Проверка на 150–500 гПа: 2×(4.7–7.6) = 9.4–15.2 против измеренных 9.2–16.4
— совпадение в пределах ~10 %. У u ошибка мягче: ×4-завышенный dx лишь занижает
∂z/∂x вчетверо (теряется ~75 % члена → невязка ~0.75·|f·v| ≈ 2.2–2.9 на 300–700,
измерено 2.7–3.9). Когерентно неверная тенденция хуже отсутствия физики: R1 портит
v именно в средней тропосфере (+2.9…+3.0 % на 300–500), где баланс самый жёсткий.
R3 (знаковые фиксы exp13; геометрия ещё легаси) уже выводит обе компоненты в минус
(u до −4.2, v до −3.5) через связку ω/z_t; R4 чинит сам градиент (диагностика
exp14: невязка u 4→1.07, v 12→0.96) и закрепляет выигрыш по уровням.

**Асимметрия u/v.** Меридиональный градиент ∂z/∂y имеет большой однознаковый
климатический средний (геострофически связан со средним западным переносом): его
переворот — когерентный bias в v_t на каждом шаге и уровне; зональный ∂z/∂x в
среднем ≈ 0, и масштабная ошибка на нём частично самоусредняется. Отсюда resid_R1:
v 6–16 против u 2–10. Дополнительно легаси-широты искажают f (по домену вдвое), что
бьёт по −f·u ровно на струе, где u максимально: coriolis(v) = 5.9–7.6 на 100–200
гПа — и там же пик resid_R1(v) = 13.1–16.4. Симметрично, после фикса геометрии
максимальные одношаговые выигрыши именно там: v@100 −28.1 %, u@50–100 −16…−17 %.

## 5. Синтез

Пять переменных сводятся к одному принципу с важной поправкой для диагностических.

**Для прогностических переменных (T, u, v, q) физ-арм улучшает уровень тогда и
только тогда, когда тенденция уравнения ловит истинную тенденцию там
(`residual_rel ≲ 1`), и вредит там, где тенденция неверна (`≫ 1`).** Чище всего —
для импульса: физика помогает по всей свободной тропосфере (resid 0.6–1.2) и
проваливается в пограничном слое (resid → 3.6), где геострофия сменяется
Экмановским балансом, невоспроизводимым грубым трением Рэлея. Для T: omega_free
(exp15) убирает плохо обусловленную ω-пару, схлопывая невязку до ~1.0 и давая
мягкое повсеместное улучшение; легаси держит 100×-неверную адиабату и портит T
наверху.

**Для диагностических переменных принцип гнётся.**
- **z** (гидростатический интеграл): скилл определяется вертикальной структурной
  когерентностью, а не поточечным замыканием. Невязка→1 у поверхности означает
  ИНЕРТНОСТЬ якоря (ПЧ≈0), а не точность; выигрыш живёт наверху, где глубок путь
  интегрирования и велик бароклинный сигнал. Корреляция Δ×невязка инвертируется
  (−0.68), omega_free делает полосу пользы сплошной (corr→−0.07).
- **r** (меряется на r, эволюционирует на q): мост Клаузиуса–Клапейрона (7–14 %/К)
  делает q-замыкание плохим предиктором r-скилла (corr +0.05). Обучаемый диабатик
  (t_and_q) реально помогает на 400–500 (осадочный сток), но невидимый в невязке
  «налог» возникает на 600–700, где физика декоррелирует ковариацию (δq, δT),
  которую эксплуатировал R0.

**Пограничный слой (≲ 850 гПа) — универсальная зона отказа** для всех переменных:
уравнения ядра лишены подсеточной физики (турбулентные потоки, Экмановский
поворот, испарение, суточный ход), которая там доминирует. Отсюда конкретный рычаг:
**маска уровня, включающая физический приор только выше пограничного слоя** (для
влажности — уже с ~925–850 гПа).

**Дуальность «короткий лид / дрейф rollout».** Приор — модель одношаговой
тенденции; его вклад максимален на шаге 1 (−15…−32 % наверху) и разбавляется по
12-шаговому free-running горизонту, пока приор считается от дрейфующего состояния.
Знак-корректная физика (пост-exp13) держит знак выигрыша по всему горизонту;
знак-сломанная (легаси) переворачивается в плюс — тот самый водораздел rollout
экспа 16, разрешённый здесь послойно.

**Связь с лестницей.** Послойный взгляд объясняет, ЗАЧЕМ каждая ступень: знаковые
фиксы **exp13** спасают катастрофические невязки наверху (z 356→7, T 105→1);
геометрия **exp14** спасает импульс в свободной тропосфере (агеострофический
остаток); omega_free **exp15** уплощает интегранд T и z; обучаемый диабатик Q_θ
(t_and_q) добавляет среднетропосферный сток влаги. Легаси (R1) — структурный
потолок: его невязки ≫ 1 везде наверху.

* Один сид (s0), общая эпоха 89; ранжирование близких армов (≤1 п.п.) не
