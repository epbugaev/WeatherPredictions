# Уравнения физического ядра — живая таблица

**Назначение.** Единственный источник правды о том, какие уравнения решают
`utils/physics_hybrid.PDE_kernel` (обучаемый прайор PI-моделей) и
`utils/physics.PurePDEKernel` (диагностика/check_physics), и в каком статусе
каждый член. **Правило ведения:** любое изменение уравнений в этих модулях
сопровождается правкой этой таблицы и [docs/consistency.md](consistency.md)
в том же коммите; статусы подтверждаются тестами
`tests/test_physics_sign_conventions.py`.

Эталон: гидростатические примитивные уравнения в изобарических координатах
(Holton & Hakim, гл. 3; Vallis, гл. 2). Внутренняя вертикальная конвенция
ядер — **ζ = −p**: `d_z` = −∂/∂p, `get_w` = w = −ω (вверх-положительная,
гПа/с); подробности — в [docs/consistency.md](consistency.md).

## Прогностические уравнения

| Уравнение | Эталон (изобарические координаты) | Реализация | Где | Статус |
|---|---|---|---|---|
| Импульс, u | ∂u/∂t = −∇·(u**V**) − ∂(uω)/∂p + f·v − ∂Φ/∂x | flux-форма: `−[d_x(u²)+d_y(uv)+d_z(u·w)] + f·v − z_x`; двойные ζ-инверсии в верт. члене гасятся | `physics_hybrid.get_uv_dt`; `physics.get_uv_dt` (advective/flux по флагу) | ✅ верно (пин-тесты); нет членов кривизны uv·tanφ/a (~1–2% от f·v) |
| Импульс, v | ∂v/∂t = −∇·(v**V**) − ∂(vω)/∂p − f·u − ∂Φ/∂y | аналогично | там же | ✅ верно; та же оговорка |
| Кориолис | f = 2Ω·sinφ, широты реального кропа | `f_field` из `lat_start_deg + dlat_deg·i` | `PDE_kernel.__init__`; `Grid.f_spherical` | ✅ верно (фикс exp 01, баг №1); `beta_plane` — регрессионный флаг |
| Термодинамика | ∂T/∂t = −**V**·∇T − ω·∂T/∂p + (R_d·T/(c_p·p))·ω + Q/c_p | адвекция ✅; адиабата с **ω = −100·w** (фикс B1, аудит 13); Q отсутствует (см. Q_θ-арм) | `physics_hybrid.get_t_t:488`; `physics.get_t_t` | ✅ верно после B1; ❗ нет диабатики Q (exp 10, структурно) |
| | | `legacy_paper`: Q = −L·z_z·w (WeatherGFT eq. 17–18) | флаг `t_t_formulation` | 🔒 регрессионная ветка, заведомо сломана (exp 01, баг №2), байт-в-байт |
| Влажность | ∂q/∂t = −**V**·∇q − ω·∂q/∂p + δ·F(T,q_s)·ω/p (насыщенная псевдоадиабата; δ=1 при ω<0 ∧ q≥q_s) | адвекция ✅; конденсация с реальным p уровней, ω = −100·w (фикс B3) | `physics_hybrid.get_q_dt:554`; `physics.get_q_dt` | ✅ верно после B3; ❗ нет испарения/подсеточной конвекции |
| Геопотенциал | ∂Φ_t/∂p = −R_d·T_t/p ⇒ Φ_t(p) = Φ_t(p_s) + ∫_p^{p_s} (R_d·T_t/p′)dp′ | `z_t = integral_z(+R_eff/p_гПа · t_t)` (фикс B2); анкер Φ_t(p_s)=0 | `physics_hybrid.get_z_zt:513`; `physics.get_z_t:825` | ✅ верно после B2; ❗ прогностическая z избыточна (exp 10: z жёстко следует T) |

## Диагностические соотношения

| Соотношение | Эталон | Реализация | Где | Статус |
|---|---|---|---|---|
| Континуити → ω | ∂ω/∂p = −∇·**V**; ω(p) = ∫_p^{p_s} ∇·**V** dp′ (анкер ω(p_s)=0) | `w = integral_z(−div)` = **−ω** (вверх-положительная) | `physics_hybrid.get_w:534`; `physics.get_w:758` | ✅ схема верна; конвенция w=−ω документирована (аудит 13); ❗ кинематическая ω шумна на 8×16 (exp 10: ×10, r≈0), `mass_consistent` — паллиатив |
| Насыщение (Магнус) | e_s = 611.2·exp(17.67·t_c/(t_c+243.5)) Па; q_s = 0.622·e_s/(p − 0.378·e_s) | поэлементный clamp экспоненты ±20 (фиксы exp 01 №4 + B4) | `get_qs` внутри `get_q_dt`; `physics._get_qs:857`; `saturation_specific_humidity` | ✅ верно; ❗ клемп занижает точность при T<−35 °C (floor e_s≈1.2e-6 Па — безопасно) |
| Уравнение состояния | p известно на уровнях | реконструкция ρ=−1/z_z, p=ρRT **удалена** (давала p<0, баг B3) | — | ✅ устранено |

## Численная схема

| Компонент | Реализация | Статус / известные ограничения |
|---|---|---|
| Горизонтальные производные | WENO-5 (Jiang–Shu), без flux-splitting, граница reflect (регион) | ✅ стенсиль верен (3.7e-6 на sin); ❗ без апвинда — только для гладких полей/frozen-фич; первый узел оси при reflect даёт производную 0 |
| Вертикальная производная `d_z` | FD-4 с делением на локальный Δp | ❗ систематика 0–5% на неравномерной p-сетке (формально несостоятельна) |
| Вертикальный интеграл `integral_z` | нижнетреугольная M_z, веса — центрированные Δp, направление уровень→поверхность | ✅ прямоугольники ~2-го порядка |
| Шаг по времени | forward Euler, `block_dt = 3600/(depth·steps)` = 400 с (v4) | ❗ для pure-physics линейно неустойчив на волновой части; CFL не лимитирует (adv 0.06, грав. 0.36); см. exp 07 + аудит 13 §3.2 |
| Ограничители приращений | `physical_clip` (капы z=500 м²/с², t=5 K, u,v=10 м/с, q=2e-3 на подшаг), `.detach()` | ✅ страховка, срез 0–6% элементов; `scale_diff` — легаси, уничтожает масштаб (не дефолт) |

**История фиксов уравнений:** exp 01 (5 багов: Кориолис, legacy t_t,
универсальная R в гидростатике, Магнус batch-remap, avoid_inf) →
EXP-GG (дефект A: NaN-грады; дефект B: conv-контаминация → `stable_physical_v2`)
→ **аудит 13** (B1 знак адиабаты, B2 знак гидростатики, B3 давление/триггер
конденсации, B4 Магнус в диагностической библиотеке).
