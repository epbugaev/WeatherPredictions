# Идея 1 — Term-bank: замороженный `PurePDEKernel.rhs()` на нативной сетке как банк по-членных признаков

Оси рамки: **A** (представление физики) + **F** (граница единиц), ремонт **B** (признак).
Статус: предложена по итогам аудита (`docs/PI_IAM4VP_integration_audit_ru.md`, находки F1–F5).

## Механизм

Убрать HybridBlock из residual-ветки PI-IAM4VP. Вместо него — безпараметрический
`utils.physics.PurePDEKernel` с честной геометрией кропа, вызываемый **не как
интегратор, а как RHS-оценщик**: `rhs()` без `step()`. Корректор получает не одну
свёрнутую `delta_phys`, а **банк членов уравнений** отдельными каналами:

```
{u_t, v_t, t_t, q_t, z_t, ω, adv_h(T), R_d·T·ω/(c_p·p), PGF_x, PGF_y, f·v − z_x} × 13 уровней
```

каждый нормирован на **свою климатологическую σ** (предвычисляется по датасету).
Раз нет интегрирования — нет CFL, нет субшагов, нет стабилизаторов-костылей;
всё считается на полном 32×64 (исчезает high-pass загрязнение ресемплинга, F4).

## Теоретическое обоснование

Каноническая форма «NN-замыкание над динамическим ядром»: NeuralGCM (Kochkov et
al., Nature 2024) подаёт в learned-physics колонку состояние и физические
тенденции ядра; ClimODE (Verma et al., ICLR 2024) — адвекция как жёсткий
признак; в параметризациях (Rasp/Pritchard/Gentine, PNAS 2018; Yuval &
O'Gorman, Nat. Comm. 2020) решающим был выбор *членов*, а не сырых полей.
Per-term σ-нормировка — аналог tendency-space нормализации GraphCast (Lam et
al., Science 2023, SI). Потребитель нелинеен — ровно то, что требует exp 09.

## Опора на факты проекта

- exp 09: линейная комбинация членов ≈ 0 ⇒ нужен нелинейный потребитель поверх
  членов, а не их фиксированная сумма.
- exp 10 Test A: T-residual с идеальным ω ≈ 0 ⇒ члены информативны, узкое
  место — ω (здесь mass_consistent по умолчанию).
- exp 12: mass_consistent ω — верный дефолт.
- Аудит F1–F5: текущий генератор фич (HybridBlock) не поставляет ни одного
  честного члена (откат уравнений, фейковая геометрия, scale_diff-инвариантность,
  полуслучайные conv на входе уравнений).

**Не входит в опровергнутое (§2 плана v2):** не интегратор высокого порядка и
не dt (интегрирования нет вообще — обход всей CFL-проблемы); не линейная
перекалибровка; не PINN-лосс.

## Скетч реализации

- `Models/PI_IAM4VP.py` (~L253): вместо `HybridBlock` —
  `self.pure_kernel = PurePDEKernel(Grid(GridConfig(H=32, W=64, lat_range_deg=(16.17, 59.77))),
  stencil='fd4', coriolis='spherical', t_t_formulation='adiabatic_omega',
  w_diagnostic='mass_consistent', boundary_x='replicate')`.
- Новый `physics_feature_mode: "rhs_terms"` (валидация по паттерну ~L314–319).
- `_physics_prior_from_state` → `_physics_terms_from_state` (денорм уже есть).
- Буфер σ-термов + tools-скрипт статистики (CPU, один проход по датасету).
- ~200 строк + конфиг. DDP: kernel без параметров; hybrid_block не
  конструировать за флагом (`find_unused_parameters` уже true).

## Фальсифицируемое предсказание

- cos(correction, t_t-терм) по-переменно становится осмысленным (сейчас его
  доминирует high-pass F4);
- RMSE T850/Z500 на h6 −1.5…3 % vs B1 при том же бюджете;
- shuffled-контроль на термах деградирует к B0 (если нет — фичи не
  используются, идея опровергнута);
- арм «plain ω vs mass_consistent ω» внутри term-bank даёт видимый сдвиг на
  T-термах (exp 10: невязка 1233→338).

Опровержение: нулевые (б)+(в) ⇒ часовая тенденция на 1.4°-сетке не извлекается
из локальных RHS-членов — сильный негативный результат для всей программы
«физика как признак».

## Риски и стоимость

+10–20 % ко времени шага (RHS на 32×64). Главный провал — корректор игнорирует
термы (диагностика: L1-норма весов первого conv по блокам каналов).
~1 arm × 3 GPU-дня (2×V100) + CPU-скрипт статов.
