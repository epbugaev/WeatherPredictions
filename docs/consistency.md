# Таблица согласованности: знаковые конвенции и единицы

**Назначение.** Сводка конвенций (знак, единицы, ориентация осей) каждой
физической величины по всем местам употребления. Цель — чтобы ошибка класса
«прошлый аудит прочитал интеграл в другую сторону» (аудит 13) ловилась чтением
одной таблицы. **Правило ведения:** новая величина или новый потребитель
существующей — новая строка/пометка здесь в том же коммите; конвенции
запинены тестами `tests/test_physics_sign_conventions.py` (класс
`HybridConventionPins`).

## 1. Базовые конвенции осей и операторов

| Объект | Конвенция | Проверка (тест/проба) |
|---|---|---|
| Ось уровней (индекс 0→12) | 50 → 1000 гПа: индекс растёт **с давлением** (вниз по высоте) | `PRESSURE_LEVELS_HPA`, буфер `pressure` |
| Ось H (широта), v4-кроп | строка 0 — юг (`lat_start_deg`), индекс растёт **на север**; d_y = +∂/∂y | комментарий конфига «grid S->N»; ⚠️ единственная неверифицированная по данным конвенция — проверить климатологией T |
| Ось W (долгота) | индекс растёт на восток; d_x = +∂/∂x | WENO-пин на sin |
| `d_z` (оба модуля) | **−∂/∂p** (= ∂/∂ζ, ζ=−p): стенсиль `[-1,8,0,-8,1]` — минус FD-4 | `d_z(p) ≈ −1` (verify-скрипт, проба 1) |
| `integral_z` / `M_z` | Σ_{j≥i} = **∫ от уровня к поверхности** (∫_p^{p_s}) | `integral_z(1)`: 1012 гПа наверху, 75 внизу (проба 2) |
| `get_w` | w = −∫_p^{p_s} div dp′ = **−ω**, вверх-положительная, **гПа/с** | дивергенция ⇒ w<0 (пин-тест) |
| WENO reflect-граница | производная в узле 0 оси ≡ 0; паддинг влияет на 2 крайние ячейки | аудит 13 §4; метрика `physics_residual_delta_edge_interior_ratio` |
