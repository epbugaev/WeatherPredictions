# Механизм интеграции физических уравнений в PI-IAM4VP — теоретическая рамка

> Этот документ — концептуальная рамка, из которой план экспериментов
> (`PI_IAM4VP_physics_experiments_ru.md`) вытекает как следствие. Он отвечает не
> «какой эксперимент запустить», а «по каким принципам физика вообще должна
> входить в сеть». Каждый принцип обоснован прошлыми экспериментами
> `docs/experiments/01–12`.

## 0. Постановка

В основе PI-IAM4VP лежит одно разложение:

```
y_hat = f_NN(x)  ⊕  g(физика(x))
```

Задача интеграции — это выбор четырёх вещей:
1. **Что** такое `физика(x)` — какой оператор и в каком представлении (ось A).
2. **Где** он подключается — вход / латент / выход / лосс / схема интегрирования (ось B).
3. **Как** комбинируется `⊕` — сложение / гейт / признак / проекция (ось C).
4. **Насколько** ему доверяют — жёстко / мягко / адаптивно (оси C, D).

Текущий код — одна конкретная точка в этом пространстве: `физика` = HybridBlock-тенденция,
`где` = входной признак корректора, `⊕` = zero-init аддитивная поправка, `доверие` = глобальный L1.
Прошлые эксперименты показали, что некоторые соседние точки лучше. Ниже — разбор по осям.

---

## Ось A — представление физики: состояние vs тенденция

- **Состояние:** `физика(x) = x_{t+1}^phys` (полный прогноз кадра).
- **Тенденция:** `физика(x) = dx/dt`, и `y = x + Δt·dx/dt`.

Код уже выбрал **тенденцию** (`feature_mode=tendency`) — и это правильно: в погоде persistence
доминирует (`x_{t+1} ≈ x_t`). Оператор состояния тратит ёмкость на воспроизведение `x_t`; оператор
тенденции учит только малую дельту, где живёт весь сигнал. Отсюда же `vs_constant` — правильная
метрика: оператор должен побеждать persistence, а не ноль.

**Незакрытый нюанс (exp 10 §C):** z **избыточна** — восстанавливается из T гидростатически (0.98×).
Физика не должна прогнозировать z как независимую переменную (это хрупкая степень свободы,
чувствительная к опорному уровню интегрирования). **Механизм-вывод:** физика прогностична по
{u, v, T, q}, а z **диагностируется** из T на каждом шаге (ср. NeuralGCM).

## Ось B — где подключается: признак vs выход vs лосс

| Механизм | Что делает | Вердикт по данным |
|---|---|---|
| **Физика как признак** (вход корректора) | NN видит `delta_phys`, решает сам | ✅ Текущий. Работает, т.к. не навязывает физику |
| **Физика как выход** (аддитивно к прогнозу) | `y = y_nn + физика` | ⚠️ Только с гейтом/zero-init — иначе тянет к неполной динамике |
| **Физика как лосс** (штраф невязки) | PINN-стиль | ❌ В осн. опровергнут (R²≤0.17): штраф за неверные уравнения вреден |

Ключевой концептуальный результат: **наивная PINN-парадигма («добавь физический лосс на выход») здесь
не работает**, потому что она предполагает, что уравнения верны, а exp 09/10 доказали структурную
неполноту (нет диабатики Q, которая в 48× крупнее адиабатики). Штрафовать сеть за отклонение от
неполной физики — тянуть её к худшему прогнозу.

**Фундаментальный принцип архитектуры:** физика входит как *советник* (признак/prior), а не *судья*
(жёсткий лосс/ограничение). Исключение — величины, физически *точные*, а не приближённые:
кинематическая неразрывность `∇·v + ∂w/∂z = 0` — тождество, не приближение; только его можно навязывать
жёстко (это делает E-ω в ω, это мог бы делать E3′ в выходе).

## Ось C — оператор комбинации: почему нужен адаптивный гейт

Сейчас: `y = y_nn + correction` со свободной свёрткой и глобальным скалярным L1. Проблема (exp 05):
**невязка физики резко режимна:**
- Средние широты, океан → физика информативна (v_res=0.32, геострофия держится).
- Тропики (f→0) → геострофический prior **вреден** (v_res=1.08).
- Горы → орография не разрешается (z-невязка 199 vs 124 над океаном).

Глобальный скаляр физически не может выразить «доверяй здесь, не доверяй там». Механизм —
**пространственно-адаптивный гейт:**

```
y = y_nn + α(x) ⊙ delta_phys + (1−α(x)) ⊙ correction,   α(x) ∈ [0,1]
```

Это не «ещё один эксперимент», а правильная форма оператора комбинации для физики, верной локально и
неверной локально. Обученная `α` — **научный артефакт**: карта «где примитивные уравнения объясняют
погоду», проверяемая против режимов exp 05 (высокий α над океаном средних широт, низкий в тропиках/горах).

## Ось D — путь градиента: два разных `.detach()`

1. **`.detach()` в rollout** (`iterative_manual.py` L117) — обрубает градиент между шагами прогноза.
   Корректор оптимизируется под 1 шаг, слеп к накоплению ошибки → чинит **E1** (truncated BPTT).
2. **`.detach()` внутри HybridBlock** (`get_w`, `scale_diff`, `q_s`, `delta`, `F_`) — обрубает градиент
   через сам физический оператор → физика работает как **фиксированный (не обучаемый) prior**.

Две философии по п.2:
- **Физика заморожена** (текущая): оператор — фиксированный референс, вся адаптация в NN. + интерпретируемость; − нельзя чинить неполноту внутри физики.
- **Физика обучаема** (снять detach, коэффициенты — параметры): «мягкая физика». + можно выучить диабатику внутри; − теряется чистота «это уравнения», и exp 12 показал NaN у обучаемого матричного оператора без mass_consistent ω.

**Вывод по механизму:** держать *ядро* уравнений замороженным (интерпретируемость), но добавить
**отдельный обучаемый диабатический член** `Q_θ` рядом:
`dx/dt = физика_замороженная(x) + Q_θ(x, солнце, облака, орография)`. Замороженная часть даёт R²=0.17
«бесплатно», обучаемая добирает нелинейный остаток — единственное работающее направление по exp 09
(линейная поправка ≈ ноль). Это **E9′**.

## Ось E — два «часа»: субшаги физики vs авторегрессия

Две вложенные временные схемы:
- **Внешний цикл** — авторегрессия IAM4VP: 6 кадров × ~1ч, неявная стековая (`pred_list`).
- **Внутренний цикл** — субшаги HybridBlock: `block_dt=1200с`, 3 субшага явного Эйлера на вызов.

Вся числовая нестабильность живёт во внутреннем цикле (exp 03: явный Эйлер на lat-lon расходится за
8–12 шагов). Рычаг — **не порядок интегратора и не dt**, а mass_consistent ω (exp 12).
**Механизм-вывод:** внутренний интегратор должен быть максимально дёшев и стабилен (Эйлер +
mass_consistent ω), а не «точен» — его выход всё равно идёт как признак, точность добирает внешний NN.
Это переворачивает интуицию «сделаем интегратор высокого порядка» (E4, опровергнут): точный интегратор
неверных уравнений бесполезен.

**Открытый под-вопрос:** должен ли `block_dt` зависеть от lead time внешнего цикла? Поздние кадры
(t+6ч) физически интегрируются на больший горизонт; сейчас `block_dt` фиксирован. Можно связать с
time-embedding IAM4VP (эта часть E5 — про согласование двух часов — не тестировалась).

## Ось F — граница физических и нормализованных единиц

NN работает в нормализованном пространстве (~N(0,1)); физика требует физических единиц (T[K], p[Па],
r→q). Режим `stable_physical` уже делает: денорм → clamp диапазонов (T∈[150,350]K, u,v∈[±150]) → r→q
Magnus → HybridBlock → q→r → ренорм → clip тенденции.

Это самое хрупкое место интеграции — здесь нужны clamp, BN-eval, tendency_clip. **Принцип:** чем больше
физики двигается в физическое пространство, тем больше стабилизаторов-костылей. E-ω снижает хрупкость
по-настоящему (убирает раскачку дивергенции в источнике), в отличие от clip (лечит симптом).
Направление механизма: заменять *стабилизаторы-симптомы* (clip) на *стабилизаторы-причины*
(mass_consistent ω; в пределе — ERA5-омега).

## Синтез: целостный механизм

```
                прогностические {u,v,T,q}   (z — диагностируется из T)
                          │
   x ──► [замороженное ядро уравнений]──► delta_phys   (Эйлер + mass_consistent ω: дёшево+стабильно)
   │              +
   │      [обучаемый Q_θ(x, солнце,облака,орография)] ──► diabatic  (нелинейный остаток)
   │                          │
   └──► [NN f_NN(x)] ──► y_nn │
                          │   │
              y = y_nn + α(x)⊙(delta_phys+diabatic) + (1−α(x))⊙correction
                          │
              (α — карта доверия физике, публикуемый артефакт)
                          │
              обучение: truncated BPTT сквозь стек, + мягкий штраф ТОЛЬКО на кинематическую неразрывность
```

**Пять принципов (каждый доказан экспериментами):**
1. **Физика — советник, не судья** (признак/prior, не жёсткий лосс) — уравнения неполны. `[09,10]`
2. **Доверие адаптивно и пространственно** (α-карта) — невязка режимна. `[05]`
3. **Замороженное ядро + обучаемый диабатический член** — линейной поправки мало, нужен нелинейный Q_θ. `[09]`
4. **Стабильность через причину, не симптом** (mass_consistent ω, не clip) — нестабильность нелинейно-CFL-типа. `[03,12]`
5. **Жёстко навязывать только точные тождества** (кинематическая неразрывность), приближённые уравнения — мягко или никак. `[04,09,10]`

**Порядок реализации (следствие принципов):**
E-ω (принцип 4, ✅ сделан) → E9′ (принцип 3) → E2 (принцип 2) → E1 (обучение) → E3′ (принцип 5, осторожно).
